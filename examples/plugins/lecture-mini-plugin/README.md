# Lecture Mini Plugin

Tiny example of plugin packaging.

It exists to show the idea, not to be a production package:

- `.claude-plugin/plugin.json` is the Claude Code-style manifest.
- `.codex-plugin/plugin.json` is the Codex-style manifest.
- `skills/repo-cartographer/SKILL.md` is the reusable workflow.

The skill body stays mostly portable; the manifest and install flow change.
